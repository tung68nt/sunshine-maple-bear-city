# 🎤 SCRIPT TRÌNH BÀY KHÁCH HÀNG (3 PHÚT)

## **TÌNH HUỐNG: Khách Nói "Vài Chục Triệu Thôi, WordPress Rẻ Mà!"**

---

### SCRIPT (Đọc Tự Nhiên):

```
"Vâng, khách hiểu rồi. Em xin giải thích tại sao có sự chênh lệch:

Nếu khách chỉ cần THÔNG TIN đơn giản (giống website WordPress cũ):
→ Em có thể dùng WordPress = 25-40 triệu (2-3 tuần xong)
   Nhưng sẽ CHẬM, plugin dễ conflict, bảo mật yếu

Nếu khách muốn website CHẤT LƯỢNG CAO (tối ưu, nhanh, bảo mật):
→ Em dùng Next.js Custom = 90-150 triệu (6-8 tuần)
   Nhanh 10x, bảo mật cao, dễ mở rộng

Khách muốn cái nào?
A) Rẻ + chậm (WordPress 25M)?
B) Chất lượng cao (Next.js 120M)?
C) Hoặc cái gì đó giữa (Webflow 50-80M)?
"
```

---

### NẾU KHÁCH NÓI "WORDPRESS THôi, CHỈ CẦN 25M"

**Trả lời:**
```
"Vâng, em đồng ý. WordPress 25M là hợp lý.
Nhưng khách cần biết:

- Trang sẽ tải chậm (3-5 giây)
- Plugins cũ có thể conflict
- Muốn thêm feature → phải cài plugin (có rủi ro)
- 3-5 năm sau → phải update lại

Nhưng nếu khách chỉ muốn website thông tin đơn giản,
WordPress 25M là OK thôi.

Khách quyết định: WordPress 25M hay Next.js 120M?"
```

---

### NẾU KHÁCH NÓI "TẠI SAO NEXTJS MẮC VẬY?"

**Trả lời:**
```
"Câu hỏi hay! Em giải thích:

WordPress 25M = mua theme có sẵn + cài plugin
- Như mua nhà mẫu prefab
- Nhanh, rẻ, nhưng hạn chế

Next.js 120M = viết code từ 0
- Như xây nhà độc lập từ nền móng
- Lâu hơn, mắc hơn, nhưng độc lập + bất cứ lúc nào mở rộng được

5 năm sau:
- WordPress 25M: cũ, chậm, bảo mật yếu → phải làm lại = 20-30M thêm
- Next.js 120M: vẫn tốt, mở rộng dễ, chỉ thêm 10-20M nếu cần feature

Nên trong dài hạn, Next.js 120M hơi mắc lúc đầu,
nhưng rẻ hơn trong 5 năm.

Khách muốn dài hạn hay chỉ cần ngắn hạn?"
```

---

### NẾU KHÁCH NÓI "OK, CÓ THỂ CHẤP NHẬN 100M"

**Trả lời - NGAY LẬP TỨC:**
```
"Xuất sắc! 100M là giá tốt nhất cho chất lượng cao.

Em đề xuất OPTION 3: SIMPLIFIED NEXTJS = 120M (nhưng có thể hạ xuống 100M)

Bao gồm:
✅ 10 trang public (Landing, About, Curriculum, Contact, etc)
✅ Gallery + Blog system
✅ Contact form
✅ Mobile responsive
✅ SEO tối ưu
✅ 12 tháng hosting
✅ Training 3 giờ

Không bao gồm:
❌ Admission form (phức tạp)
❌ Tour booking (phức tạp)
❌ Admin dashboard full

Thời gian: 6-8 tuần
Thanh toán: 30% down, 35% mid, 35% finish

Khách đồng ý?"
```

---

### NẾU KHÁCH NÓI "OK, NHƯNG CẮT MỘT SỐ FEATURE"

**Trả lời:**
```
"Được, khách muốn cắt gì?

Có thể cắt:
- Giảm số trang (10 → 8 trang) = -5M
- Không có CMS complex (chỉ static) = -5M
- Giảm hosting (từ 12 → 6 tháng) = -1M

Nên:
- Cắt trang: 120M → 115M
- Cắt CMS: 120M → 115M
- Cắt hosting: 120M → 119M

Khách cắt gì thì giá hạ bao nhiêu?"
```
