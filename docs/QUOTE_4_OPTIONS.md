## 🎓 TẠI SAO CUSTOM DEV MẮC HƠN WORDPRESS?

### **WordPress (25-40M):**
- Dùng theme có sẵn → 1 tuần
- Plugin có sẵn → không cần viết code
- Hosting chia sẻ → rẻ
- **Nhưng:** Slow, heavy, plugins conflict, bảo mật kém

### **Custom Next.js (90-150M đơn giản, 400M+ full):**
- Viết code từ 0 → 4-12 tuần
- Performance tối ưu → trang tải nhanh hơn 10x
- Bảo mật cao hơn
- Có thể scale dễ dàng
- Quản lý content sạch (không plugins)
- **Nhưng:** Đắt hơn vì đòi hỏi dev skills cao

### **Quy tắc chung:**
- "Rẻ" thường = theme cũ, performance kém
- "Mắc" = custom, performance tốt, bảo mật cao
- Giữa = No-code builder (Webflow)
